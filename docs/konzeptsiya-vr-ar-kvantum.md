# VR/AR-квантум: веб-платформа по аналогии с «урокробототехники.рф»

**Дата:** 2026-11-14 · **Автор:** предложения для VR/AR-квантума (12–18 лет)

---

## 1. Что представляет собой референс (и почему он работает)

`урокробототехники.рф` — «Симулятор Ардуино онлайн» (RobX): бесплатный браузерный Arduino-эмулятор, которым удобно вести уроки без парка железа. Разберём его анатомию, потому что это и есть готовый «рецепт»:

| Слой | Что там есть | Зачем это педагогу/ученику |
|---|---|---|
| Zero-install | Всё работает в браузере, на русском, без Arduino IDE | Урок можно вести с любого ПК, даже слабого |
| Среда разработки | Редактор кода с подсветкой, компиляция/запуск по кнопке «Play» | Полный цикл: написал → запустил → увидел |
| Визуальное «железо» | Arduino Uno/Nano/Mega/ESP32/Pico + десятки модулей (серво, LCD, OLED, NeoPixel, HC-SR04, MPU-6050…) + пассивные компоненты и моторы | Ученик собирает схему кликами, а не пайкой |
| Инструменты измерений | Осциллограф (В/дел, время/дел, каналы), генератор сигналов, вход аудиокарты | Урок выглядит как настоящая лаборатория |
| Серийный монитор | Порт с настройкой окончаний строк, автопрокрутка, копия | Отладка так же, как на реальном железе |
| Облако | Вход по email/коду, сохранение и «открыть из облака» | Проект ученика не теряется между занятиями |
| Позиционирование | «Урок» в названии домена, поддержка, дата сборки | Это методический инструмент, а не просто игрушка |

**Ключевой принцип референса:** закрыть разрыв между «хочу на занятии» и «нет устройства под рукой» — всё остальное (облако, осциллограф) добавляет ценность уже после того, как снят барьер входа.

## 2. Что мешает VR/AR-квантуму сегодня (аналог той же боли)

- Unity/Unreal + Blender нужно **устанавливать и обновлять** на всех ПК; нужны мощные машины, ГБ места, лицензии, версии «плывут» от занятия к занятию.
- Шлемов (Quest/Pico/Vive/Moverio) меньше, чем учеников; одна гарнитура на 12 человек — очередь.
- Пороги входа: C#, 3D-математика, пайплайн «модель → экспорт → сцена → билд → запуск».
- Проекты теряются между домами и занятиями; показ результата родителям = «принеси флешку».
- AR на iPhone/Android — зоопарк: Quick Look, Scene Viewer, WebXR, ARCore — ученику непонятно, куда смотреть.

**Вывод:** ровно та же ниша, что у онлайн-симулятора Arduino: *браузерная, бесплатная, русскоязычная среда, где VR/AR-опыт получается без шлема и без установки, а потом «поднимается» до реального железа.*

## 3. Проект «УрокVR.РФ» — концепция-аналог «урокробототехники.рф»

### 3.1. Одно предложение

> Бесплатная браузерная лаборатория виртуальной и дополненной реальности для школы: собираешь 3D-сцену, даёшь объектам поведение, «надеваешь» шлем или наводишь камеру телефона — прямо в браузере.

### 3.2. Прямая карта соответствий «Arduino-симулятор → VR/AR-лаборатория»

| Робототехника (референс) | VR/AR-аналог | Комментарий |
|---|---|---|
| Онлайн-компилятор Arduino | **WebXR-песочница**: кнопка «▶ Запустить» рендерит сцену в браузере | Three.js / A-Frame / Babylon.js — open-source, без лицензий |
| Код с комментариями на русском | **Уровень 1 — блоки** (Blockly, русские блоки), **уровень 2 — JavaScript**, **уровень 3 — псевдо-C# → экспорт в Unity-C#** | Лестница: Scratch → JS → C#, как в самом квантуме |
| Серийный монитор | **Консоль событий сцены**: логи, «прикоснулся к объекту → …», печать в HUD | Отладка без Unity-консоли |
| Осциллограф | **«Осциллограф рендера»**: графики FPS/frame time, draw calls, полигонов, WebXR frame-loop; «виртуальная 6DoF-осциллограмма» трекинга | Очень сильная методическая фишка: видно, ПОЧЕМУ сцена «тяжёлая» |
| Генератор сигналов | **Генератор событий/анимаций**: синус, мигание, прыжок, таймер-триггеры для объектов | Быстро демонстрировать физику и анимации |
| Библиотека контроллеров | **Шаблоны миров**: «Класс», «Музей», «Космос/орбитальная станция», «Город», «Лаборатория» + библиотека готовых объектов (GLTF) | Аналог Blink — стартовый шаблон «VR-hello world» |
| Модули (серво, LCD, HC-SR04…) | **VR/AR-компоненты**: HMD-эмулятор, контроллеры, телепорт-точка, «схватить», триггер-зона, кнопка, AR-маркер, светильник, табличка с текстом, звук | «Модульный» монтаж VR — тот же визуальный принцип |
| Проводка кликами | **Граф событий (нодовый, как Unreal Blueprints-lite)**: объект → событие → действие | Понятно без единой строки кода |
| Осциллограф+В/дел | Настройки камеры/мира: FOV, IPD/масштаб, «метры в сцене», размер аватара | Учит правильным единицам и масштабу VR |
| Облако RobX, «открыть из облака» | **Облако проектов + публичная ссылка-портфолио** | Ученик отправляет ссылку на защиту проекта — идеально для предзащиты |
| IR-пульт, LCD 1602… | **AR-модуль «оживи фото»**: печатаешь QR/маркер → наводишь камеру → модель/анимация/видео поверх маркера | Прямое попадание в типы проектов кванторианцев (AR-меню кафе, AR-инструкция по мебели) |

### 3.3. Четыре модуля, которые покрывают программу VR/AR-квантума

**Модуль А. «VR-песочница» (ядро).** Редактор сцен: примитивы + библиотека GLTF + свет + физика (cannon-es) + события. Просмотр: мышь/WASD в браузере → потом «Смотреть в шлеме» (WebXR: Quest/Pico через браузер гарнитуры — Chrome) или режим «телефон как окно» (device orientation). Без шлема — полноценный урок, со шлемом — вау-эффект.

**Модуль Б. «AR-лаборатория» (телефон).** WebXR-AR для Android (Chrome) + AR.js-маркеры как запасной путь + USDZ/Quick Look-экспорт для iPhone. Сценарии: (1) маркерная AR — «ожившая» схема/плакат; (2) AR без маркера — модель на столе; (3) QR-«AR-визитка» объекта. Практикум «меню кафе с AR» и «инструкция по сборке» — прямо по типовым проектам квантума.

**Модуль В. «Механика VR» (теория в симуляторе).** Виртуальные стенды: устройство HMD (линзы, FOV, стереобаза, трекинг 6DoF), какая задержка motion-to-photon допустима, почему VR требует 72–90 FPS, как считается масштаб сцены. Аналог «внутренностей Arduino на макетной плате» — железо видно изнутри.

**Модуль Г. «Мост в Unity».** Экспорт сцены в описание (JSON + assets) и генератор C#-скриптов/сцены под Unity — кульминация года: «в браузере сделал → в Unity открыл». Для наставников — библиотека конвертаций (A-Frame entity ↔ Unity GameObject).

### 3.4. Режим для наставника (то, чего нет у обычного просмотрщика 3D)

- **Конструктор заданий:** учитель собирает «карточку задания» («расставь планеты в порядке удаления от Солнца», «найди 3 ошибки в VR-сцене музея»), ученик получает ссылку, выполняет, отправляет обратно.
- **Проверка/чек-лист:** критерии как на защите проектов (масштаб, FPS, наличие инструкции, звук).
- **Класс и журнал:** группы, список учеников, статусы работ, комментарии; экспорт в PDF/CSV для журнала.
- **Готовые сценарии занятий (методичка):** 2 академ. часа × 2 раза в неделю — по 30–40 уроков первого года: от «первой сцены» до «VR-музея».

### 3.5. Портфолио и защита

Каждый проект = публичная WebXR-ссылка + автообложка (скриншот первого кадра) + описание. Единая «стена работ» квантума — мотивация, реклама набора, база для предзащиты (как в реальных VR/AR-квантумах Волжского и Екатеринбурга, где дети защищают портфолио-музеи).

## 4. MVP: что сделать первым (8–10 недель, 1–2 разработчика)

**Фаза 1 (недели 1–4) — «играбельная песочница»:**
- Three.js-сцена: примитивы + 20 GLTF-объектов (мебель, планеты, животные, школа), свет, тени, физика (падение/столкновения).
- Блоки на Blockly («при старте», «при касании», «создать объект», «играть звук», «телепорт») + консоль событий.
- Кнопка «Запустить», смена вида «от первого лица / свободный полёт», замер FPS. Одна готовая сцена «Космос».

**Фаза 2 (недели 5–8) — «урок и сохранение»:**
- Аккаунты по email + сохранение/открытие проектов (как «Robx»), ссылки-портфолио.
- 10 заданий учителя + 3 готовые сцены (музей, космос, мебельный AR-маркер).
- Режим WebXR (Quest/Pico через браузер) и маркерная AR на Android.

**Фаза 3 (недели 9–10) — «методичка»:**
- 12 готовых уроков (возраст 12–14), методические карточки, PDF для печати, onboarding-тур для ученика и для наставника.

**Не брать в MVP:** настоящий Unreal/Unity в браузере (пиксельные шейдеры, Nanite), редактор Blender в браузере — это scope-killers; начинать надо с малого и работающего.

### Метрики успеха пилота
- ≥70% учеников заканчивают первое занятие с опубликованным проектом;
- ≥1 готовый проект на ученика за четверть;
- время подготовки урока наставника < 15 минут;
- 0 установки ПО на ПК квантума;
- ≥30% учеников открывают проект дома (ссылка работает без регистрации — только для просмотра).

## 5. Технические развилки и риски

| Вопрос | Реалистичный ответ |
|---|---|
| Двигатель в браузере | **Three.js/A-Frame** (максимум контроля, обучение, WebXR из коробки) или **Babylon.js** (лучше WebXR-инструменты). **PlayCanvas** (MIT, open-source) — «веб-Unity» с готовым редактором, если нужно быстрее. Unity WebGL — тяжело и закрыт, не брать за основу. |
| iOS + AR | WebXR в Safari нет → дублировать: USDZ + Quick Look (авто-просмотр) либо AR.js-маркеры в Safari как «план Б». |
| Слабые ПК квантумов | WebGL2, лимит полигонов в библиотеке объектов (<30k), LOD, отчёт «вес сцены» — тот самый «осциллограф». |
| Трекинг в WebXR | Immersive-vr на Quest/Pico работает в браузере гарнитуры; на ПК без шлема — эмуляция мышью; на телефоне — датчики. |
| «Оцифровка Unity-мира» | Прямой импорт Unity-сцен не нужен: экспорт «браузер → Unity» (описание сцены генератором) реалистичнее. |
| Импортозамещение/санкции | Весь стек — open-source, без зарубежных облаков: статика на любом РФ-хостинге, бэкенд FastAPI/Node + PostgreSQL + S3-совместимое хранилище (можно свое), почта по SMTP. |
| Безопасность детей | Без чатов и открытой публикации без модерации; ссылки-портфолио по сути «только смотреть». |

## 6. Дорожная карта «по аналогии» (что после MVP)

1. **«Осциллограф VR» Pro** — графики frame time, WebXR-статистика, «сколько draw calls в твоей сцене», бейджи «Оптимизировано».
2. **Библиотека кванториум-миров** — обмен сценами между квантумами сети (Екатеринбург, Волжский, Махачкала…): «сцена недели».
3. **Олимпиадный трек** — задачник по VR-принципам + стенд-симулятор «собери VR-тренажёр» (целевые проекты: «виртуальный тренажёр социального работника», «VR-медлаборатория»).
4. **Конкурс проектов** с публичной стеной работ и голосованием.
5. **Интеграция с Blender** — авто-оптимизация моделей (децимация) перед загрузкой: «подготовил модель для VR одним кликом» — ответ на боль «модель весит 800 МБ».
6. **Сертификация уровней** «VR-кванторианец 1/2/3» по аналогии с модулями программы.

## 7. Риски проекта
- «Игрушка вместо методики» → сразу делать конструктор заданий и журнал, а не только песочницу.
- «Только для сильных» → уровневость (блоки → JS → C#) и 12 готовых уроков.
- «Зависло на железе» → всё работает без шлема; шлем = опция, не зависимость.
- Scope creep (хотим «Unity онлайн») → фиксируем MVP, дальше только по метрикам.

## 8. Что нужно для старта
- 1 frontend (Three.js/TypeScript), 1 full-stack (бэкенд + облако), методист-наставник VR/AR на 0.25 ставки.
- Пилот в одном квантуме (2 группы, 8–10 занятий) → сбор обратной связи → доработка → масштабирование на сеть.
- Инфраструктура: VPS/облако РФ, домен вида `урокvr.рф` / `vrokul.рф` (по аналогии с `урокробототехники.рф` — имя-домен = готовый маркетинг).
